# Drop set ¿sirven? #gym #gimnasio #ejerciciosgym #entrenogym #entrenam...

Drop Set. ¿Son necesarias? ¿Van en la pena añadirlas a tu entrenamiento?
Lo primero que voy a hacer es explicar que es una Drop Set.
Una Drop Set básicamente es realizar una serie y cuando acabas ésta seguidamente sin descanso, hacer o trabajando el peso.
Son dos series seguidas simplemente que no hay descanso entre ellas.
Y comparado esto con las series normales, ¿qué diferencia tienen además del descanso? ¿Son mejores para la hipertrofia?
Pues no, y esto es debido que al no descansar entre serie y serie, la fatiga del sistema nervioso central
hace que no podamos reclutar unidades motoras de alto umbral y tengamos que reclutar las bajas.
Cuando nosotros reclutamos las bajas, accionamos menos fibras en ese músculo que cuando reclutamos las unidades motoras de alto umbral.
Así pues, siendo dos series, estas dos series son menos efectivas que dos series convencionales.
Ya que nosotros, cuando hacemos dos series normales, sí descansamos entre serie y serie,
quitando la fatiga del sistema nervioso central y pudiendo reclutar unidades motoras de alto umbral, así pudiendo hacer una serie de alta calidad.
Y aunque la Drop Set nos vamos a acercar al fallo o vamos a ir al fallo,
la diferencia más obvia sería que en la segunda serie realizada inmediatamente
crearía un estímulo de crecimiento más pequeño porque no descansamos entre series,
lo que a la larga significa que vamos a ganar menos vaso muscular debido a que esa serie es menos eficiente.
Y todo esto es debido al poco descanso o al nulo descanso entre serie y serie,
por lo cual entendemos que las series normales son superiores en el contexto de hipertrofia.
Las Drop Set las podemos utilizar para limitar la sesión de entrenamiento
o cuando no tengamos el tiempo suficiente como para hacer nuestra rutina normal.
Incluso algunas personas lo pueden añadir por diversión ya que para tener una buena adherencia a un entrenamiento
este debe ser divertido para esa persona aun siendo algo menos eficiente,
no quiere decir que nunca se deba utilizar.
